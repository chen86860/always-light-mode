# Chrome Web Store Listing — Long Description

Store console → Store listing → Description. One block per language.

## English (en)

Always Light Mode keeps every website in light mode — even sites that turn dark on their own.

Keep your system in dark mode and still read the web in light. Just install it: no setup needed.

WHY IT WORKS
• Works on sites with their own dark theme, not just ones that follow your system setting
• No dark flash while pages load
• Keeps working on modern web apps and pages that change as you browse

EASY TO USE
Click the toolbar icon to:
• Turn the extension on or off
• Skip any site that looks better as it is
• Report a site that doesn't look right

PRIVATE AND LIGHTWEIGHT
No tracking, no data collection. Everything runs on your device, and it's only a few kilobytes.

Website: https://always-light-mode.emmmm.dev/
GitHub: https://github.com/chen86860/always-light-mode

## 日本語 (ja)

Always Light Mode は、すべてのウェブサイトをライトモードで表示します。勝手にダークになるサイトも例外ではありません。

システムはダークモードのまま、ウェブはライトで読めます。インストールするだけで、設定は不要です。

選ばれる理由
• システム設定に従うサイトだけでなく、独自のダークテーマを持つサイトにも対応
• 読み込み中に一瞬暗くなることもありません
• 最新のウェブアプリや、閲覧中に内容が変わるページでも動作

かんたん操作
ツールバーのアイコンをクリックして：
• 拡張機能のオン／オフ
• そのままの方が見やすいサイトを除外
• 表示がおかしいサイトを報告

プライバシーと軽さ
トラッキングもデータ収集も一切なし。すべて端末内で動作し、サイズはわずか数 KB です。
